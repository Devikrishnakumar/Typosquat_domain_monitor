# CyberSentinel landing page

The static landing page introduces the defensive brand-impersonation monitoring project. It describes the Certificate Transparency discovery workflow, evidence collection, heuristic risk triage, analyst review, and simulation mode without presenting scores as confirmed phishing verdicts.

## Run locally

From the repository root, double-click `start.bat` to start the landing page, dashboard, API, and built-in background monitor:

The launcher opens [http://localhost:8765](http://localhost:8765) after the services are ready. The dashboard is at [http://localhost:8501](http://localhost:8501), and API documentation is at [http://localhost:8000/docs](http://localhost:8000/docs). Keep their service windows open while using the project.
